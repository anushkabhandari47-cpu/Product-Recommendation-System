# 🛍️ Product Recommendation System

## 📌 Overview

The Product Recommendation System is a Flask-based web application that recommends products based on user preferences. It uses machine learning techniques to generate personalized recommendations and provides an interactive user interface for browsing products.

---

## ✨ Features

- Product recommendation using Machine Learning
- Search and filter products
- Personalized recommendations
- Interactive product catalog
- Flask backend
- HTML, CSS, JavaScript frontend
- SQLite database support

---

## 🛠️ Technologies Used

### Backend
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- SQLite

### Frontend
- HTML5
- CSS3
- JavaScript

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/<your-username>/<repository-name>.git
```

### Navigate to the project

```bash
cd "Product recommendation"
```

### Create a virtual environment

```bash
python -m venv .venv
```

### Activate the virtual environment

Windows

```bash
.venv\Scripts\activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
cd backend
python app.py
```
