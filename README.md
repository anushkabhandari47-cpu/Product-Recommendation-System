# 🛍️ AI-Powered Smart Product Recommendation System

An intelligent e-commerce recommendation platform built using **Flask**, **Machine Learning**, and **SQLite** that delivers personalized product recommendations based on user preferences, shopping behavior, and mood. The system also features an AI-powered shopping chatbot, secure user authentication, wishlist management, and an intelligent solution to the cold start problem.

---

## 📌 Overview

The **AI-Powered Smart Product Recommendation System** is designed to enhance the online shopping experience by providing personalized product recommendations using machine learning techniques.

One of the biggest challenges in recommendation systems is the **Cold Start Problem**, where new users have no previous interaction or purchase history. This system overcomes that challenge by collecting a few preference-based inputs such as favorite categories, styles, colors, and shopping interests to generate relevant recommendations from the very first interaction.

The platform also introduces **Mood-Based Shopping**, allowing users to discover products that match their current mood or occasion. An integrated **AI-powered shopping chatbot** assists users with product-related queries, making product discovery faster and more interactive.

---

# ✨ Features

- 🛍️ **Personalized Product Recommendations**
  - Generates intelligent recommendations using machine learning based on user preferences and shopping interests.

- 😊 **Mood-Based Shopping**
  - Enables users to explore products based on their current mood or occasion, creating a more engaging shopping experience.

- 🚀 **Cold Start Problem Solution**
  - Solves the cold start problem by asking new users a few preference-based questions and generating personalized recommendations even without previous purchase history.

- 🤖 **AI Shopping Chatbot**
  - An integrated chatbot that assists users with shopping queries, product discovery, and recommendation guidance.

- 👤 **User Authentication**
  - Secure user registration and login system for personalized shopping experiences.

- ❤️ **Wishlist & Favorites**
  - Allows users to save favorite products and manage a personalized wishlist for future purchases.

- 🔍 **Product Search**
  - Search products quickly using keywords.

- 🎯 **Preference-Based Recommendation Engine**
  - Recommends products based on user-selected preferences and interactions.

- 💻 **Responsive User Interface**
  - Clean and interactive interface developed using HTML, CSS, and JavaScript.

- ⚡ **Flask Backend**
  - Efficient backend handling recommendation logic, chatbot interactions, authentication, and business logic.

- 🗄️ **SQLite Database**
  - Stores user accounts, product information, wishlist data, recommendation data, and application records.

# 🚀 Installation

## Clone the Repository

```bash
git clone https://github.com/anushkabhandari47-cpu/Product-Recommendation-System.git
git branch -M main

```

## Navigate to the Project

```bash
cd "Product recommendation"
```

## Create a Virtual Environment

```bash
python -m venv .venv
```

## Activate the Virtual Environment

### Windows

```bash
.venv\Scripts\activate
```

### Linux/macOS

```bash
source .venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
cd backend
python app.py
```
